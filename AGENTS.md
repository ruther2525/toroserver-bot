# Git workflow

- You may commit completed changes for the requested task without asking for confirmation. Keep unrelated working-tree changes out of the commit and use the repository's configured commit signing.
- You may push work for the requested task to its intended remote branch without asking for confirmation when both the local and destination branches are other than `main`. Pushing from or to `main` requires an explicit request.
- This repository is public. Before committing or pushing, review the staged diff or outgoing commits for credentials, private data, and machine-specific configuration.
